# Neon Wallet Aero
Your self-custodial and open-source blockchain wallet as browser extension.

## Husky
Run:
```
npm run prepare
```

## Development
Run:
```
npm run dev
```

## Build
Run:
```
npm run build
```

## Lint and typecheck
Run:
```
npm run lint && npm run typecheck
```

## Download SVGs
Run:
```
npm run icon
```

## Technologies used
- React
- TypeScript
- Vite
